# Datos (no incluidos en el repositorio)

**¿Primera vez? Sigue el [tutorial paso a paso](TUTORIAL_DESCARGA.md)** (Windows, Mac y Google Colab). Abajo, el resumen.

Descargar la base **«ENS + Defunción (Mortalidad) 2023»** desde https://epi.minsal.cl/bases-de-datos/
(enlace directo: https://epi.minsal.cl/wp-content/uploads/2026/07/Base_ENS_Mortalidad_2023.zip).

El archivo se llama `.zip` pero es un **RAR**: se abre con 7-Zip, WinRAR o The Unarchiver.
Contiene tres `.sav` (ENS 2003, 2009-10, 2016-17). Copiar en esta carpeta el de 2016-17:

`Base de datos Encuesta Nacional de Salud 2016-2017(ENS)+DEF2023.sav`

Condiciones de uso del Minsal: solo para investigación, citar la fuente y enviar copia de las publicaciones.
https://epi.minsal.cl/condiciones-de-uso/
