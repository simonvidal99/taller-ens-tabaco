# Taller: tabaco y riesgo de muerte con la ENS 2016-17

| Archivo | Qué es |
|---|---|
| `GUIA_FACILITADOR.md` | Objetivos, tiempos, clave de respuestas y puntos de enseñanza |
| `taller_tabaco_PARTICIPANTES.ipynb` | Cuaderno con ejercicios en blanco (para repartir) |
| `taller_tabaco_FACILITADOR.ipynb` | Mismo cuaderno con soluciones y salidas ejecutadas |
| `taller_tabaco_RESUELTO.ipynb` | Versión neutra: paso a paso, explicaciones, soluciones y salidas ejecutadas, sin indicaciones de uso |
| `presentacion_taller_tabaco.pdf` | Presentación (Beamer, 17 diapositivas); fuente en `presentacion/` |
| `datos/` | Base «ENS 2016-17 + defunciones 2023» del Minsal (34 MB, `.sav`) |

**Fuente de los datos:** Ministerio de Salud de Chile, Departamento de Epidemiología — https://epi.minsal.cl/bases-de-datos/
Uso solo para investigación, citando la fuente.

**Cómo ejecutar:** abrir un cuaderno en Jupyter o Google Colab (en Colab, subir el `.sav` a la carpeta `datos/`).
Librerías: `pandas numpy scipy pyreadstat lifelines matplotlib` (la primera celda las instala).

**Verificación:** el cuaderno del facilitador se ejecutó completo, sin errores, con Python 3.14 y las versiones actuales de las librerías.
